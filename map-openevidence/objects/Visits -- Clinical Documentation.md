# Visits -- Clinical Documentation

A live product (launched August 2025): automatically generates medical notes from
patient conversations. Moves OpenEvidence upstream of the evidence query into the
visit itself -- capturing the encounter and producing structured clinical documentation,
reducing administrative burden for clinicians. This is the first product extension
beyond search.

Held-by [[OpenEvidence]] · extends [[Clinical Search Engine]] ·
feeds into [[EHR Integration Layer]] · used-by [[US Clinician Base]]

- Hits: documentation time, clinical note quality, EHR data completeness.
- Does not hit: the evidence retrieval layer or the prior authorization workflow.
