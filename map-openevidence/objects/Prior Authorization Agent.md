# Prior Authorization Agent

An agentic workflow capability in rollout: drafts prior authorization letters with
supporting evidence for medical necessity, built through the [[Tandem Health]]
partnership (announced April 2026). Extends from the evidence retrieval in
[[Clinical Search Engine]] into the administrative layer -- generating the insurer
documentation a clinician needs to get a treatment approved. Part of the broader
move from search to agentic task automation.

Developed-with [[Tandem Health]] · extends [[Clinical Search Engine]] ·
part-of the [[Search to Agentic Automation]] gradient ·
anticipated-by [[Enterprise Health Systems]]

- Hits: prior authorization turnaround time, clinician administrative burden,
  revenue potential for [[OpenEvidence]].
- Does not hit: the evidence corpus or the visit documentation layer.
